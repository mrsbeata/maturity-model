## The five levels

| Level | Name | In one line |
|---|---|---|
| 100 | Initial | It's switched on. Ad hoc, reactive, person-dependent. |
| 200 | Managed | Some routines exist, mostly in people's heads. Recommendations, not policies. |
| 300 | Defined | Documented, repeatable, owned. The level every competency should reach. |
| 400 | Predictable | Measured and automated. Human error and boring work are largely gone. |
| 500 | Optimizing | Continuous improvement with feedback loops. World class, and never finished. |

[Read the full level descriptions](overview/microsoft365-maturity-model--intro.md#maturity-levels)
